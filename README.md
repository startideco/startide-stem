# Startide STEM

Static website for Startide STEM, hosted with GitHub Pages.

## Files

- `index.html` — main website
- `styles.css` — layout and visual design
- `script.js` — mobile navigation and current-year footer

## Publishing

Upload these files to the root of the `startide-stem` repository. GitHub Pages should be configured to deploy from the `main` branch and `/ (root)` folder.

## Before public launch

Update:
- Confirmed grades
- Dates and times
- Tuition
- Registration link
- School-approved program wording
- Final instructor biography
- Policies and waiver links
